# Ma trận parity DSH → Galaxy Blackhole

> **Sinh tự động — KHÔNG sửa tay.** Sinh lại: `bun run tools/lint/parity-matrix.ts`; kiểm tra lệch: thêm `--check` (đã nằm trong `bun run gate`).
> Nguồn dữ liệu đóng băng ở `docs/contracts/data/dsh-packages.json` (kèm cả mô tả gốc tiếng Anh của từng package).

## 1. Nguồn và quy tắc đếm

| Nguồn | Chi tiết |
|---|---|
| Cây plugin đã compose của APP (profile blackhole @ 5439, harness 0.2.1-alpha.4) | `.parity/dumps/2026-10-17T05-37-06/ours.yml` (1392 dòng) |
| Cây của Oracle A (4001) để đối chiếu | cùng thư mục `.parity/dumps/<ts>/oracleA.yml` — tại lần chụp: 0 thêm, 0 thiếu, 0 đổi |
| Bằng chứng hợp đồng | `tests/contract/*.test.ts` + fixture `tests/contract/fixtures/` |
| Metadata package DSH | ~/tmp/galaxy-blackhole/dsh-upstream/packages — README frontmatter description, đối chiếu `galaxy-blackhole/docs-blackhole/DSH-PLUGINS.md` |
| Snapshot dùng để sinh tài liệu | `docs/contracts/data/dsh-packages.json` (schema 2, sinh ngày 2026-10-17, 205 row) |

**Quy tắc đếm — đọc kỹ để không hiểu lệch nhau:**

- **row (dòng plugin)** = số dòng `- id:` ở **thụt lề 0** trong dump → **205** row. Đây là đơn vị thi công: mỗi row là một plugin trong cây.
- **tên package** = số giá trị `name:` **duy nhất** trong các row đó → **199** tên.
- **package gốc** = sau khi gộp các row cùng gói nhưng khác subpath (`/tools`, `/host`, `/startup`, `/list-agents`, `/model-selection-settings`) → **195** gói.
- Con số **323** là tổng số dòng `- id:` **kể cả entry lồng trong `config:`** (118 entry lồng ở thụt lề 6/10). Con số đó KHÔNG phải số row plugin — dùng nó để đếm tiến độ sẽ sai.
- Vì vậy *“205 row / 195 gói”* và *“323 dòng `- id:`”* là hai cách đếm khác nhau của **cùng một dump**, không mâu thuẫn.
