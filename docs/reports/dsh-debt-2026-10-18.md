# Nợ DSH còn lại toàn cục — đo 18/10/2026

> Reviewer: tm-reviewer. Đây là **danh sách đo được** (grep/đếm), KHÔNG phải đề xuất sửa ngay.
> Mục tiêu cuối của dự án: **không còn gì liên quan DSH**, nên các literal dưới đây là việc của wave cuối.
> Mỗi mục ghi: literal · số chỗ · đường dẫn · vì sao chưa đổi được ngay.

## 1. URI scheme protocol — `dsh-resource://` (47 chỗ trong `packages/*/*/src`)

```bash
grep -ro 'dsh-resource://' packages/*/*/src --include=*.ts | wc -l   # 47
```

| đặc điểm | giá trị |
|---|---|
| số chỗ | **47** |
| vì sao chưa đổi | là **hợp đồng dữ liệu** giữa resource provider (host) và consumer (client, sidebar, plan, skill…). Đổi một phía ⇒ mọi `@file`/`/plan`/preview không resolve. Bản gốc DSH cũng dùng đúng scheme này. |
| hướng xử lý (wave cuối) | đổi **đồng thời** host+client sang `gbh-resource://` + test round-trip; hoặc giữ nếu muốn tương thích ngược với session cũ |

## 2. Persist key — `name: "dsh.*"` (5 chỗ)

```bash
grep -ro 'name: "dsh\.[^"]*"' packages/*/*/src --include=*.ts | wc -l   # 5
```

| đặc điểm | giá trị |
|---|---|
| ví dụ đo được | `dsh.workspace.view` (`packages/client/ui-workspace` — artifact dòng 2230: `persist: { name: "dsh.workspace.view" }`) |
| vì sao chưa đổi | đổi key ⇒ **mất preference đã lưu** của người dùng (thứ tự/ nhóm workspace, view state) ⇒ cần migration đọc key cũ một lần |
| hướng xử lý | thêm bước migrate: đọc `dsh.*` → ghi `gbh.*` → xoá key cũ |
