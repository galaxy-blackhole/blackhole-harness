### 2.3 Chín hàm phụ — viết lại y hệt

- **`parseRequest(method, schema, value)`**: `safeParse` hỏng ⇒ `RemoteError("gateway/bad-request", "invalid payload for " + method, { issues })`.
- **`namespaceView(descriptor)`**: chiếu **từng field** — `ns · autoGenerate · schema · value · base? · user? · applies · secrets[{path,set}] · revision`. Vì Gateway trả kết quả nghiệp vụ **không giải mã**, field lạ sẽ lọt ra ngoài nếu không chiếu tay.
- **`rejected(ns, error)`**: nếu `settingsConflictOf` (đối tượng có `code === "SETTINGS_CONFLICT"` + message + expected/actual) ⇒ `RemoteError("settings/conflict", message, { ns, expected, actual }, { cause })`; còn lại ⇒ `RemoteError("settings/rejected", messageOf(error), { ns }, { cause })`. Ghi chú của bản gốc: bên ghi cũ là **kết cục riêng**, không phải yêu cầu sai — client phải đọc lại rồi ghi lại.
- **`credentials.write(ref, fn)`**: mọi từ chối ⇒ `RemoteError("credential/rejected", message, { ref }, { cause })`; **chi tiết chỉ nêu tên ref, không bao giờ mang giá trị bí mật trở ra**.
- **`messageOf(error)`** · **`isAborted(signal)`** (đọc lại trạng thái sau mỗi lần await) · **`credentialRef(ref)`** (brand tên theo grammar).

**Hằng và schema**: `MAX_DESCRIBE_REFS = 64` · `credentialRefSchema = z.string().regex(/^[A-Za-z_][A-Za-z0-9_]*$/)` · `describeRequestSchema = z.object({ refs: z.array(credentialRefSchema).max(64) })` · `setRequestSchema` · `unsetRequestSchema` · `settingsNamespaceRequestSchema = z.object({ ns: z.string().min(1) })`.
